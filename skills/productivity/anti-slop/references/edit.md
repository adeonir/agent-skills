# Edit

The report that follows the edit.

## When to Use

Loaded before editing: the format of the What changed report.

## Report

ALWAYS use this exact template structure:

```markdown
## What changed

- [pattern or principle]: "[original wording]" becomes "[new wording]"; "[original wording]" becomes "[new wording]"
- [pattern with a mechanical change]: [count] replaced
- Open: "[wording left in place]", [why it stays]
```

Write one line per pattern or principle, with every pair of original and new wording it accounts for. Write a cut as "[original wording]" cut, and a reorganization as its reason. Give only the count for a mechanical change, such as a dash or a curly quote. Write one Open line per item the edit leaves for the writer, and omit the line when there is none.
