# Self Check

Judgment checks to run on an edit before returning it.

## When to Use

Loaded for the rewrite mode, after the script runs clean. Mark each check pass or fail. Facts, literals, and protected blocks are checked by the script and the isolated subagent, not here.

## Checks

1. Would the writer recognize the edit as their own voice, with the voice signals from Step 1 intact and strong sentences left alone?
2. Does the edit match the register, and does a supplied writing sample still control vocabulary, cadence, punctuation, and quirks?
3. Is every change backed by a principle or a supported catalog pattern, with catalog words kept where they are technical, quoted, or deliberate?
4. Was each fake-profound kicker deleted rather than rewritten, and does the piece end on a concrete point, takeaway, or next action?
5. Was each weasel attribution with no source cut and recorded in What changed?
6. Is the edit free of robotic symmetry, repeated sentence shapes, and stacked punchy fragments it did not have before?
7. Would the edit sound natural read aloud to a sharp colleague?
8. Does the output follow edit.md for the input form?
