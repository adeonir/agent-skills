# Assessment

Describe the current experience of the project site from its code and its rendered pages.

## When to Use

Loaded when a project site exists, to produce the observations the concept builds on.

## Evidence

Read the code for structure, content, and declared movement. Render the site for what the visitor perceives: pacing, scroll behavior, and how sections connect do not show in code. Both feed the assessment, and every claim rests on a capture or a code location.

## Rendering

- Local code: find the dev command in the project's manifest or instruction files, start it in the background, and stop it when the assessment ends. Run no production build, deploy, or publish.
- Confirm the rendered page is the project's own: its visible text matches the code. When the configured port is already in use, start the server on another port and leave the project's files unchanged.
- When the server does not start, whether from missing dependencies, missing environment variables, or any other failure, stop and ask the user. Never invent a value, never print the contents of an environment file, and install dependencies only with the user's approval. When the user chooses to continue without a render, assess from the code and record the limit.
- Published site: render it and read only. Submit no form and trigger no action.
- When no way to render exists, ask the user how to proceed.
- Capture the page from top to bottom, as a full-page capture or at several scroll positions, at a desktop viewport width and at a 390 px viewport width. Cite a capture by its viewport width and its position on the page. Keep captures and server logs out of the project's tracked files.

## What to describe

For each section in visitor order: what it communicates, and where it connects to the previous one or stands apart from it. Then the whole: what the experience asserts, its pacing, and the interactions and movement present with what each does. Observations only; no verdict against a concept.

## Limits

Record in the document what could not be assessed and why.
